# てじゅんひょう（あさ・かえりの じゅんび）

特別支援学校のiPadで使える、**朝の準備・帰りの準備向けスケジュール（手順表）Webアプリ**です。
サーバー不要・インストール不要で、**GitHub Pages** に公開してSafariで開くだけで使えます。

## 主な機能

- **2つの表示モード**
  - **いちらんモード**：上から「1、2、3…」と全体を見通しながらチェックできます。
  - **1まいずつモード**：「いま やること」を1枚大きく表示。気が散りやすい児童・生徒にも使いやすい設計です。
- **実物写真＆DROPSシンボル対応**
  - iPadのカメラで撮った写真（本人のリュック、ロッカー、連絡帳かご等）をそのままカードに登録できます。
  - [DROPS公式サイト（droptalk.net/symbol/）](https://droptalk.net/symbol/) からダウンロードしたDROPSシンボル（PNG画像）を、手順編集画面の **「🖼️ DROPS / シンボル集」** からまとめて（またはフォルダごと）取り込んで、名前検索でワンタップ選択できます（出典：© Droplet Project）。
  - 写真やシンボルがないときも絵文字アイコンから選べます。
- **誤操作を防ぐ「せんせいモード」**
  - 右上の「⚙️ せんせい」ボタンを **1.5びょう長押し** すると編集画面が開きます。
  - 手順の追加・編集・順番変更、手順表の追加（「きゅうしょく」「そうじ」等）、文字サイズ、順番ロック、効果音、読み上げ設定ができます。
- **安心のローカル保存＆バックアップ**
  - 登録した写真や手順は **iPad本体の中にだけ保存** され、インターネットには送信されません。
  - バックアップファイル（`.json`）を書き出して、別のiPadにコピーすることもできます。
  - A4用紙などにそのまま印刷する機能もあります。
- **オフライン動作（PWA対応）**
  - ホーム画面に追加すれば、Wi-Fiが不安定な教室でもアプリのように全画面で動作します。

## GitHub Pages で公開する手順（無料）

1. [GitHub](https://github.com/) にログインし、右上の **「＋」→「New repository」** をクリックします。
2. リポジトリ名（例：`tejun-schedule`）を入力し、**Public** を選んで **Create repository** をクリックします。
   - ※個人情報や児童の写真はコードに含めないため Public で問題ありません。
3. 作成したリポジトリで **「uploading an existing file」** をクリックし、このフォルダ内のファイル・フォルダをすべてアップロードして **Commit changes** を押します。
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.json`
   - `sw.js`
   - `icons/` フォルダ（中のPNGファイル3つ）
4. リポジトリ上部の **Settings** → 左メニューの **Pages** を開きます。
5. **Build and deployment** の **Branch** で `main`（フォルダは `/ (root)`）を選んで **Save** をクリックします。
6. 1〜2分ほど待つと、`https://<ユーザー名>.github.io/<リポジトリ名>/` というURLが表示され、公開完了です！

## 学校のiPadでアプリとして使う手順

1. iPadの **Safari** で、公開されたURLを開きます。
2. 画面右上の **共有ボタン（□に↑）** をタップします。
3. **「ホーム画面に追加」** を選び、右上の **「追加」** をタップします。
4. ホーム画面に「てじゅんひょう」のアイコンが追加され、タップすると全画面で起動します。

### もし学校のフィルタリングで `github.io` が開けない場合

- 自治体のフィルタリングで `*.github.io` がブロックされている場合は、同じファイルをそのまま **Cloudflare Pages** や **Netlify**（いずれも無料）にアップロードすると別ドメインで開けることがあります。
- 情報担当の先生に `github.io` のホワイトリスト登録を相談する方法もあります。
